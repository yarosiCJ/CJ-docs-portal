# Clear Junction API docs portal

This repository builds a **static documentation portal** (for Pages deployment):

## What lives where

- **API Reference**: <Link to="/reference">/reference</Link> (renders `openapi.yaml` via Redoc)
- **OpenAPI file**: <a href={useBaseUrl('/openapi/openapi.yaml')}>/openapi/openapi.yaml</a>
- **Postman**: <Link to="/docs/postman">collection page</Link>
- **Additional parameter descriptions**: `Docs → Reference → CoP` (synced from contract sources)
- **Integration scenarios**: `Docs → Integration` (synced from integration sources)

## Local preview

Start the docs portal locally:

```bash
npm run start
```

Build static files:

```bash
npm run build
```

## Where content comes from

The portal publishes:

- OpenAPI spec at `/openapi/openapi.yaml`
- Postman collection at `/postman/Clear_Junction_API.postman_collection.json`
- Additional guides and integration scenarios under `Docs`
