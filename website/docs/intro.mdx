# Clear Junction API docs portal

This repository builds a **static documentation portal** (for Pages deployment):

## What lives where

- **API Reference**: <Link to="/reference">/reference</Link> (renders `openapi.yaml` via Redoc)
- **OpenAPI file**: <a href={useBaseUrl('/openapi/openapi.yaml')}>/openapi/openapi.yaml</a>
- **Postman**: <Link to="/docs/postman">collection page</Link>
- **Additional parameter descriptions**: `Docs → Reference → CoP` (synced from contract sources)
- **Integration scenarios**: `Docs → Integration` (synced from integration sources)

## Local preview

Start commands (note: `sync` runs automatically before `start/build`):

```bash
npm run start
```

Build static files:

```bash
npm run build
```

## Where content comes from

The `npm run sync` script copies into this project:

- bundled OpenAPI contract: `web/openapi.bundled.yaml` (published as `/openapi/openapi.yaml`)
- schemas: `openapi-built/components/schemas/*`
- `docs/reference/cop.md`
- Postman collection JSON
- Integration scenarios (Markdown)

Paths can be overridden via env vars: `OPENAPI_SPEC_FILE`, `OPENAPI_SCHEMAS_DIR`, `COP_MD`, `POSTMAN_COLLECTION`, `INTEGRATION_DOCS_DIR`.
